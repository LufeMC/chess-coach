# Vendored ChessKit

Source: https://github.com/chesskit-app/chesskit-swift
Version: 0.17.0 (commit 44ef7a1)
License: MIT (see LICENSE)

Vendored rather than consumed as an SPM dependency because this app needs API
that upstream keeps private, and because upstream is a single-maintainer,
pre-1.0 project where minor versions break API.

## Local changes

### 1. `Zobrist.swift` (new)

Adds `Position.zobristKey: UInt64`, a stable position identity.

Upstream's `Position: Hashable` uses Swift's `Hasher`, which is **seeded
randomly per process**. That is correct for in-memory dictionaries and unusable
for anything persisted — the same position hashes differently on the next
launch. Since positions are stored in SQLite and compared across sessions, this
fork computes a proper Zobrist key from a fixed table generated by a
deterministic PRNG (splitmix64 with hardcoded seeds).

The key covers piece placement, side to move, castling rights, and a
*capturable* en passant file — and deliberately excludes the halfmove/fullmove
clocks, since two positions differing only by clock are the same position for
repetition purposes.

### 2. `Board+Attacks.swift` (new)

Adds public `attackers(of:by:)`, `isSquareAttacked(_:by:)`, and
`leastValuableAttacker(of:by:)`.

Upstream's attack machinery is entirely private and only `legalMoves` is
exposed. `legalMoves` excludes moves onto one's own pieces, so it can express
what a piece captures but never what it *defends* — which makes static exchange
evaluation and hanging-piece detection impossible to build on top of it. Those
two detectors are core to the app's coaching, so this fork surfaces the
underlying bitboard queries.

### 3. `Board.swift` — repetition keyed on Zobrist

`positionHashCounts: [Int: Int]` keyed on `position.hashValue` became
`positionKeyCounts: [UInt64: Int]` keyed on `position.zobristKey`, for the
stability reason above (and because the 64-bit hash was being truncated to
`Int`). The draw check also changed from `== 3` to `>= 3` so a position
reaching a fourth occurrence still reports the draw. Added public
`Board.repetitionCount` so the UI can warn before a repetition rather than only
reacting to `state`.

### 4. Removed the `chesskit-cli` target

Dropped the executable target and with it the only third-party dependency
(`Dye`). The library target has no dependencies.

### 5. Platform floors raised to iOS 18 / macOS 15

Matches the app; upstream targets iOS 12 / macOS 10.13.

## Upstream bugs that did NOT reproduce

Research flagged these as open upstream issues. Regression tests were written
for each and **all pass against 0.17.0 unmodified** — they were fixed upstream
before this release. The tests are kept in `ForkRegressionTests.swift` so a
future upstream merge cannot silently reintroduce them:

- **#50** — en passant missing from `legalMoves(forPieceAt:)`
- **#82** — SAN omitting capture notation for en passant
- **#56** — threefold repetition miscounted

## Merging upstream changes

Diff against the 0.17.0 tag, reapply the four changes above, then run
`swift test`. The fork regression suite is the guard: if any of it fails after a
merge, the merge reintroduced a bug the app depends on not having.
